# Mapa kontekstu — Strona Gosi

| Zadanie | Czytaj |
|---|---|
| Obsługa i szybki start | `README.md` |
| Treść i konkretna poprawka | `site_content.js`, `index.html` |
| Wygląd / zachowanie | wskazany plik HTML oraz powiązany CSS/JS |
| Ustalenie zakresu / starsze decyzje | tylko właściwy istniejący opis lub makieta |
| Publikacja | konfiguracja hostingu, potwierdzona decyzja użytkownika, wyniki odbioru |

To odrębny projekt od Strona Gosi Cinematic. `wersje/`, `Archiwum/` i pliki rewizji są historią; nie ładuj ich domyślnie. Przed publikacją sprawdź pochodzenie zdjęć i potwierdzenie danych realizacji.

Nie przeszukuj historii, plików graficznych i innych stron bez konkretnego powodu. Zmiany kodu wykonuj tylko w zakresie danego zadania.
