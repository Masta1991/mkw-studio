# Strona Gosi — jak korzystać

Portfolio MKW Studio i oferty projektowania wnętrz Małgorzaty Wojtysiak.

## Start

Otwórz ten folder jako projekt w aplikacji agenta. Poproś: „Otwórz lokalny podgląd tej strony i wskaż miejsce zmiany tekstu [sekcja]”. Pliki strony to `index.html`, `site_content.js`, `main.js`, `style.css`, materiały w `Zdjecia/`. `index.html` jest wejściem do podglądu; agent powinien dobrać lokalny serwer, gdy wymaga go zachowanie strony.

## Praca z agentem

- Treść: „W projekcie Strona Gosi popraw opis [sekcja], zachowaj styl i pokaż podgląd”.
- Kontrola: „Sprawdź stronę na telefonie i komputerze, zgłoś konkretne błędy”.
- Zakończenie: „Zapisz aktualny stan i jeden następny krok”.

Podawaj rezultat i sekcję. Agent zaczyna od `AGENTS.md` oraz `CONTEXT_MAP.md`, dobiera potrzebne pliki i testy. Nie musisz wklejać całej historii rozmowy.

## Ważne pliki i granice

To odrębny projekt od Strona Gosi Cinematic. `wersje/`, `Archiwum/` i pliki rewizji są historią; nie ładuj ich domyślnie. Przed publikacją sprawdź pochodzenie zdjęć i potwierdzenie danych realizacji.

Podgląd lokalny i publikacja to osobne działania. Nie podawaj agentowi haseł w dokumentacji. Niektóre strony pobierają fonty, mapy lub biblioteki z internetu; lokalny adres strony nie oznacza pełnej pracy offline.

Audyt 2026-09-15 uporządkował dokumentację; nie zmieniał ani nie testował frontendu/backendu.
